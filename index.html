HTML

  • Html is a tag based language.
  • It is a language used to define and display your content in the form of a webpage.
  • Characters between angular brackets(< and >) are called tags.

HTML Document Object Model

  • The DOM model is a standard which provides mutual interpreteton whare grammar of a language can be associated
    with and can co exist on various operating systems.
  • In HTML,every file is interpreted as a DOM -tree where heirarchy of said file is defined.

Tags in HTML
  • Tags are very important in HTML.
  • Without tags a website can't be developed using HTML.
  • Here are some main tags used in HTML:

HTML Tag

  • Any HTML is identifined with the tag-pair.
  • Anything written between this tag-par is recognized as HTML document.
  • The extension of a html file is .html

Head Tag

The tag-pair is defined, where tags can be placed which are not part of the main body of html, like title of the webpage.

Title Tag

  • Just like every document has a name, the 'title' tag- pair allows your webpage a name.
  • In case if multiple pages open up in your browser,a webpage is easily identifiable.
  • The title of a webpage is visible on the browser tab.

Body Tag

  • The main part of the html is 'body',all the main constituents html,of the document are arranged in the 'body' tag-pair.

Tags for Headings

  • The headings are of different levels provided by the html.
  • There are 6 defined levels where 1 is the largest and 6 is the smallest.
  • The headind tag pair looks like (h2......h2) for 2 level heading.
